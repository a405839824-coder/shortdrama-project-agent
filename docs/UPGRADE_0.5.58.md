# 0.5.58 审计结果保存、回读与多文件隔离

本版仅修正通用审计流程。固定母版、来源剧情、台词、基础声线和语速规则不变；管理员及员工继续使用同一服务，权限边界不变。

## 已复现的原因及修正

- 外部原件没有历史 canonical sidecar 时，可以完成只读审计，但派生报告文件曾错误进入生产文件读取器而被拒绝。现在回读首先验证签名审计证书、原件真实字节、元数据、可见审计结论及内容映射。无 sidecar 仅在已绑定的只读审计路径允许；存在但损坏的 sidecar 仍拒绝。不补造生产证据。
- openpyxl 整本保存会归一化与审计无关的空字符串、富文本和公式缓存。合成样例已复现值改变拦截。现在仅替换审计工作表部件，或增加缺失的审计页；保留其余原部件字节和样式索引。已有 sidecar 仅更新审计页摘要，未提供的 sidecar 不新建。真实历史文件是否恢复导出必须另在线验证。
- 同一工单和审计周期曾把不同外部文件归入同一统计及 Ledger 作用域，混用首轮数据并阻止较早文件追加复核。新事件按服务端确定的根文件来源链隔离。旧事件、轮次、证书保持原样，旧记录继续按原规则重建验证，不以新文件的结果覆盖历史。

审计副本具有自己的真实原始字节摘要；比较它与无 sidecar 原件的内容映射时，仅排除该必然不同的文件字节摘要，其余字段逐项相等。对外读取仍返回副本的实际摘要，不把原件摘要冒充副本摘要。

## 发布及验收

本次维护脚本位于 `outputs/audit_flow_0558_release`。切换前隔离入口并等待在途审计完成，为当次完整 Library 运行目录和 exports 制作新的签名快照。启动只接受 `.upgrade-0558`、版本 `0.5.58`、合同 `library-runtime-transfer-0558-v1`；历史 `.upgrade-0557` 不重放、不删除。新实例逐文件及受保护配置核验通过后才能恢复入口。

发布后从插件读取真实运行版本，执行规定自检，再用当前规则重绑未变化原件的复核记录、重新签发并回读真实派生文件。旧签名不自动成为新版本结论。已检查、有确证问题、证据不足、已签报告、文件回读通过分别统计；首稿缺少原始留存证据时准确率仍为空，不以修改后文件或软件测试推算。

软件合成回归不代表真实剧本通过；所有真实分镜审计和文件核验必须经线上插件完成。员工共用后端更新不等同于已完成员工客户端独立验收。
