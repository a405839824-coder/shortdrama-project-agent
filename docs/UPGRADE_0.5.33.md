# 0.5.33：生产决定依据与整镜交付约束

此前字段归属一致仍不能防止共用错误前提，单列合规也不能证明整镜可执行。本版把此前六类历史问题及六项设计补充合并为唯一规则源中的 PP-01 至 PP-12，生成规则合同，并要求新生产使用先冻结的来源图计划。

新增计划绑定原文和规则/模板指纹、初始世界与各输入决定；声明角色初始知情、真实获知事件、知道/猜测/误解/伪装的区别，以及本镜必须交付的事实、动作、声音和可见窗口。服务器保存原始请求后，使用实际来源与模拟数据检查，缺计划、决定漂移、提前知情和整镜交付冲突不能形成可审分镜。合法导演选择、静止镜头、画外声及关闭纸窗透光继续允许。

生产计划和新代码都纳入既有重编译指纹。兼容 canonical 单独报告新生产计划未验证，不以字段合规冒充生产计划通过。模板仍使用 0.5.32 的 R5 投影实现与 27 字段/10 列合同，画面内容仍无数字制作时间码；内部时序保留。

## 覆盖与边界

| 内容 | 本版执行方式 | 尚需独立判断 |
|---|---|---|
| 原文事实与设定 | 实际跨度、事实ID、必要使用；计划依据分层 | 蕴含、遗漏、导演选择合理性 |
| 人物与物体状态 | 既有状态模拟；冻结初态和动作；派生结果重算 | 任意接触/未建模动作 |
| 反应与认知 | 逐事件前置、角色知情；受限同场对白获知 | 信念依据、复杂感知、非线性故事时间 |
| 整镜声画 | 必需事件和声音集合、逐点可见部位、实际信息使用 | 完整网格遮挡、辨字、表演自然度 |
| 光影与音色 | 既有同源光源、字段与声音合同；纳入计划锁定 | 最终图像、真实音频时长与语气 |
| 全入口和统计 | 新MCP/生产CLI必须有计划；原始尝试先留档；兼容路径明确标识 | 聊天外未提交内容无法被插件观察 |
