# 0.5.37 同源动作执行修复

本版解决源文中的起身、坐跪、跌倒、过门、拿放物件、落杯、穿戴、抓腕和掌掴等事件缺少可执行类型，以及同镜多人对白被迫拆分的问题。动作、前后状态、画面字段和接触声音由同一份决定派生，保留实际手、物主、对象、落点、次数和事件顺序。

新增独立心声和原文明确的禀报收悉渠道；心声不能变成场内对白或旁白事实，听到禀报不能变成已经证实。切镜桥接仅能省略普通走位，不能省略核心源文动作。输入与边界见[动作合同](../skills/shortdrama-storyboard/references/source_actions_0537.md)。

独立表格导出和完整校验共用同一个对白/声线语法模块，避免导出路径依赖CLI的导入环境。分集节拍及独审证据把心声绑定到真实心理音轨事件、原文和发生时段，错误地声明为画面事件仍会被拒绝。

沿用27字段、11个音色标签、十列母版和唯一正式交付回执。未修改原有集数/时长政策、预检和独立审计门禁、Producer权限或员工连接限制。字段语法只追加四条受控接触音描述，知识取得模式只增加实际源文禀报；相应历史基线作显式版本迁移。

软件合成测试与真实小说验收分开记录。本说明描述实现范围，不等于已经部署，不证明真实集次通过，也不证明员工在ChatGPT/Codex重新登录及新装验收完成。
