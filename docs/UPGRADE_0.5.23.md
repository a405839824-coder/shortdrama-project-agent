# 0.5.23：室内光影判断与技能同步修正

0.5.22 已建立室内外分流，本次修复实际场景检查中仍能漏过的普通烟雾、英文 halation、卧房/书房/账房/厅堂别名，以及由光影字段自行添加香炉来证明局部烟气的情况。同时取消“梦幻感必须使用扩散/晕染”的矛盾要求。

普通室内使用清澈空气、漫射明暗和可辨背景。梦幻感可通过低饱和色彩、自然浅景深与具体神态呈现。室内烟气必须同时具有已存在的来源、局部范围、不扩散/不遮挡约束与可辨背景；真实火场也不授权全画面镜头扩散。有烛光不自动添加烟。真实烛火/灯芯边缘允许极轻微局部 halation。

门窗开合状态先由场景建立，光影字段不能自行开窗；已开的门不能授权闭合窗户射入光束。室内实际开口及逆光用途成立时可保留逆光关系，空气仍默认清澈；可见光束另须真实散射介质和局部范围。

保留 27 个 canonical 字段、四个独立光影字段、19 个公共工具、THG-17 错误码及独审 v8 结构。运行规则与校验器指纹变化后，旧证书不能作为本版本的新检查结果。既有分镜、对白、项目快照和历史审计记录不在本次修改范围。

验证覆盖普通室内、烟气来源与范围、否定式词组、开闭门窗、清澈室外逆光、实际灯火局部高光，以及原有正式母版、Agent 生命周期、打包与服务端集成检查。
