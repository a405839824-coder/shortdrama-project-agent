# 0.5.24：统一规则、单镜计时与冲突修正

本版实施《分镜规则修改总方案_合并修订版》。保留同一用户任意认证窗口连续生产、审计、修复和导出的能力；后台工单、独立审计身份、签名证据和历史状态不合并。保留 27 个母版字段、10 列导出、三个连续正时长阶段、静态 GPT 投影和 19 个公共工具。

## 规则与执行

| 范围 | 本版处理 |
|---|---|
| 规则同步 | `rule_registry.json` 成为统一可编辑注册源；运行规则、原子规则、错误目录、任务卡等八份视图确定性生成，并校验内容漂移 |
| 旧规则 | 当前换窗指令、写死的 2.8 字/秒及固定呼吸/反应/镜尾加时退出执行；历史兼容和签名证据保留，不物理删除旧项目记录 |
| 台账 | 项目运行台账作为权威；全局汇总引用项目事件，不重复登记同一问题 |
| 单镜与章节计时 | 使用同一配置和口径，逐发言、逐阶段核对；明确先后依赖串行计时，可并行行动共用时间，停顿按身份与位置去重 |
| 默认语速 | 暂用 `provisional-zh-ordinary-v1` 候选约 5 发音单位/秒，4.5—5.2 仅为试验范围，不是厂商上限；不得把低音量或低音区一律写成慢速 |
| 时序证据 | 放入既有 `prevention_evidence.audio_workflow.timing`，不增加镜头顶层字段；动作须绑定实际人物、正文依据、所在阶段及依赖 |
| 心理音轨 | 单独计入发声时间；跨镜引用同一身份与连续片段，不重复复制音轨文本；无依据的音轨重叠不放行 |
| 原句保护 | 服务器权威源文绑定原句出现身份、顺序、指纹及字符范围；合法拆镜可通过，遗漏、重复、错序、换人及伪造候选源文均拦截 |
| 表演与重音 | 按具体人物及眼部可见时段检查视线、眼睑、眨眼；允许有依据的不眨眼和无歧义的同人视线继承；所有重音词绑定实际发言 |
| 室内光影 | 分别验证空气清澈、背景可辨、曝光正常，并拦截相反描述；烟气来源、范围和每扇门窗状态分别核对 |
| 室外与夜景 | 清澈空气中的有源逆光不必附带雾；可见光束另需散射介质；局部火焰晕光、反射高光与全画面扩散分开处理 |
| 连续性 | 比较光源、门窗和空间状态；允许等义表述和有机位依据的反打，不以一句“合理反打”替代证据 |
| 服务联动 | 场景预检使用完整音轨时间上下文；时长、对白、音色或动作变化不能复用旧计时预检；旧历史证书和恢复边界保持冻结 |

## 计时结果的边界

这次是软件规则升级，不是视频语速标定。原先偏慢的固定预算与重复加时已移除，但不能据此宣布实际生成已经准确。候选配置明确显示 `not_measured`；仅有未标定标签或过空提示不会升级成硬错误。按所选配置超出实际阶段仍是文本预算失败，须重排时间或按原句拆镜，不能删改原句过关。

数字、英文目前按可见发音单位近似并提示复核，未建立逐词实际读法的语音对齐。实测配置必须有受信任的模型、声线规格指纹和已复核对齐证据，不能由候选分镜自行声明为实测。正文时间戳也不保证生成器达到音频级精度。

后续仍需用同模型、同音色、可核对原文的实际样本检查完整度、预测误差及听感，再登记合格配置。有剧情意义的沉默和反应继续保留。

## 发布验证

核心运行时包含原有 228 项与新增 242 项规则回归，共 470 项。发布还要求服务端全部 41 个测试模块、服务自检、HTTP、stdio、插件结构和技能结构检查通过。测试样例同步当前契约不改变原有故障断言；实际运行结果记录在发布 PR 和维护工单中。

版本升级不重写用户历史分镜、对白、工作簿、项目快照、审计记录或已签署证据；不自动替用户签核项目，也不把规则发布当作历史交接恢复。
