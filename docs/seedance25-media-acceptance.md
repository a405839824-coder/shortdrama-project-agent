# Seedance 2.5 双库：实际素材与成片待验证清单

候选版本：0.5.69 R2；记录日期：2026-10-29。

**当前结论：全部实际素材/成片项目均为 NOT_RUN / not_verified。**
本次仅修改插件并进行软件检查，没有向即梦或火山API提交视频生成任务，没有消耗生图/视频额度，也没有替任何真实项目确定画风。不能从代码测试推导风格稳定率、成功率、口型准确率或无字幕保证。

## 已由软件负责的范围

明确选库与子风格；完整视觉卡和内容指纹；已登记正向风格冲突及有限否定范围；视觉参考声明对应关系；制作计划冻结；正式分镜和关键帧文本投影一致。软件证据和实际媒体验收分别记录。

## 分库成片验证

对每个真实项目，先锁定其明确选定的渲染方式和视觉卡，再用同一段源文、对白、音色和时长做对照。需要更换库时另建候选并重新冻结，不在一次生成中混合两库。以下是待执行的验证设计，不是测试结果。

| 库 | 场景 | 重点观察 | 当前状态 |
|---|---|---|---|
| 动漫3D | 单人近景对白 | 造型、皮肤/发丝材质、口型、原词与时长 | NOT_RUN |
| 动漫3D | 双人交流及喜剧反应 | 人物身份不串、反应幅度符合人物、不会自动变Q版或异常发光眼 | NOT_RUN |
| 动漫3D | 古装夜景 | 原光源与方向不变、暗部可读、卡通/写实/三渲二不漂移 | NOT_RUN |
| 动漫3D | 接触或动作镜头 | 接触因果、动作顺序、空间连续性和结果保留；不靠删动作提稳定率 | NOT_RUN |
| 仿真人 | 单人近景对白 | 自然皮肤/发丝、无塑料化、原词口型和音色一致 | NOT_RUN |
| 仿真人 | 双人交流及喜剧反应 | 身份、嘴型和声音归属清楚；不继承动漫造型 | NOT_RUN |
| 仿真人 | 古装夜景 | 肤色、衣料和暗部可信；原光源关系不变 | NOT_RUN |
| 仿真人 | 接触或动作镜头 | 身体关系、手部和接触结果正确；无自动动画化 | NOT_RUN |
| 动漫2D（若项目选用） | 线稿上色或绘制 | 线条/色块规则连续，未变成三维模型或真人影视外观 | NOT_RUN |

每条实际记录至少保存：源文版本、冻结计划指纹、库指纹、视觉卡指纹、素材文件哈希、实际模型与模式、原始提示词、输出文件及哈希、逐项问题、检查结论。没有生成的条目保持NOT_RUN；缺素材或缺文件的条目保持无法核验，不能填PASS。

若出现偏色、磨皮、眼睛发光等问题，先定位参考素材、视觉卡、具体提示词或模型输出，再做相应修订。不得为掩盖生成失败而更改保护对白、角色基础音色、剧情结果或原计时规则。重试后的结果另存，保留失败样本与原因。
