# 0.5.60：外部审计入口记录与受控恢复

本次仅修复外部工作簿审计入口引用未持久化记录的问题，以及由此产生的历史断链。生产规则、模板、语速、人物声线、剧情和原件保持不变。

入口事件先真实持久化，再公开引用它的交接单；分页和重绑定提前返回不得留下悬空引用。现有历史缺失记录不能依据引用倒造旧 ID、时间、耗时或签名。

历史处理使用原件哈希、已签交接、审计证书、修正包、审计事件和覆盖快照的精确绑定。先预演，再按计划哈希执行，创建当前时间的新恢复事件和待独审交接，明确记录旧事件原件缺失。恢复只重建可验证的继续工作路径，不等于恢复旧事件原件、不等于内容审计通过，也不清除历史失败或未知结论。

部署使用 `.upgrade-0560` 的一次性签名状态迁移；冻结并核验真实运行中项目及导出文件，启动恢复后逐字节核对，禁止重放旧版本迁移清单。软件检查和恢复回执不代替修正版的完整线上独立审计及正式文件核验。
