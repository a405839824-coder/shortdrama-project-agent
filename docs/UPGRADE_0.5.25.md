# 0.5.25：旧工作簿母本迁移

旧表已有完整正式母版，却缺少服务器绑定的 canonical。旧组合列与公式、多行声线解析也会阻止无损恢复。本版增加严格的原件解析器及受控迁移流程，使明确批准的当前文件能够进入完整预检、独立机审和签证。

入口仍是现有 `migrate_project_state`，新目标为 `workbook-canonical-v1`。预演锁定源文件、原始SHA、登记缺口、来源工单、全部集数与镜头、27字段哈希、公式及确定性转换明细。执行校验同一计划SHA，签名日志建立可恢复、可重放的专用生产身份。常规待审门禁不变，其他历史交接不变；失败草稿和质量阻塞继续生效。

该身份只能提交完整原件范围内的原始字段或预演列出的确定性规范化字段，不能增加剧情、改写对白、删除镜头或走delta/patch。全部场景和全量预检通过后，常规原子提交生成新的canonical、工作簿和PENDING_AUDIT交接。原件字节及元数据不变，旧缓存不冒充新解析。独立审计继续使用不同权限根、真实八层证据及精确指纹签发结论。

现行规则注册源和派生视图统一标记0.5.25，规则内容、约5发音单位/秒候选及所有既有门禁保持一致；新增内容是迁移能力声明。软件测试使用合成输入，不把用户剧情或证据夹带进测试数据。测试结果须与发布提交对应；升级完成不代表任何真实分镜已通过。

操作参数与失败处理见[技能迁移流程](../skills/shortdrama-storyboard/references/workbook_canonical_migration.md)。
