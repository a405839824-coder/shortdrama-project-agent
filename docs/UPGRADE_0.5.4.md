# 0.5.4 模板硬门禁集成升级说明

0.5.4 把此前未并入云端主线的模板硬门禁移植到 0.5.3 的会话绑定、独立审计和无API性能诊断基线上。它不增加 canonical 字段，不恢复 Seedance 批次，也不允许正式母版或 GPT 投影写回 canonical。

## 生效范围

- `THG-01`：每镜`生成限制`、正式母版及 GPT 投影各自明确且仅出现一次`9:16竖屏`。
- `THG-02`：阻断空分隔符及相邻完全重复的转场短句。
- `THG-03`：GPT 关键帧只从静态白名单字段投影，阻断时间、运镜、转场、对白、口型和声音过程。
- `THG-04`：正式单镜执行文本禁止“同上、承接上一镜、保持上一关键帧”等跨镜代指。
- `THG-05`：保护对白按说话人、正文、标点、顺序和多行分段逐字闭合。
- `THG-06`：单镜可识别主要人物最多三人。
- `THG-07`：单镜恰好一个主机位和一个核心动作阶段。
- `THG-08`：起始状态不得提前包含本镜动作结果。
- `THG-09`：新输出的道具状态必须结构化，同一时点唯一持有人，相邻镜首尾不得跳手。
- `THG-10`：镜头容量计入对白、标点停顿、说话前呼吸、动作、听者反应和至少0.2秒镜尾稳定。
- `THG-11`：canonical、正式投影、GPT投影和XLSX反向解析按 UTF-8 NFC + LF 做一致性与多行保真校验。
- `THG-12`：生产只写`PENDING_AUDIT／未签发结论`，问题计数、独立审计 trace、证书及审计指纹保持空；独立审计签发后另建不可变 overlay。

单镜执行字段继续禁止`BGM`字面量和主动配乐指令；负面音乐限制统一为`禁止额外配乐`。

## 兼容性

- 当前插件版本：`0.5.4`
- 分镜 Schema：`R10.1`
- 工作流：`R10-PG1`
- 输出契约：`R10-SPC-1`
- MCP 工具：15 个
- 无API性能诊断仍要求插件 `0.5.3` 或更新版本，并只在用户明确要求时启用。
- 旧`正式分镜母版`、GPT投影、Seedance提示词和批次字段只读迁移并从新 canonical 剥离。

## 发布门禁

发布前必须同时通过：

- 73 项 R10 黄金测试；
- 25 项严格提示词契约测试；
- 11 项公共场景生态测试；
- 16 项 Agent 生命周期测试；
- 22 项全项目 Agent 测试；
- 207 项插件单元、集成、安全、事务、增量和 XLSX 测试；
- stdio 与 HTTP MCP 冒烟，均报告版本 0.5.4 和 15 个工具；
- 插件与技能清单验证。

云端只有在主分支部署成功、`/health` 返回 0.5.4、ChatGPT 连接发现 15 个工具，并由`get_agent_status(full_self_test=true)`签发绑定当前规则与验证器指纹的新证书后，才算部署完成。
