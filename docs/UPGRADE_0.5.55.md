# 0.5.55：事件来源与人物知情

实际握手、付款或回应需要原文依据，但这不表示人物在开场已经知道之后的事件。旧生产计划把两种证据混为一类，迫使合法事件使用不成立的初始知情声明。

本次仅区分真实事件来源与实际使用的信息。本人发言的发生不证明句中命题为真；本人动作的结果须在真实完成后使用。明确阅读后才发生的反应仍须有原文、真实物件、视线及先后关系，不导入原文未提供的文字，不宣称像素辨字已验证。

保留真实听取、条件事件、私有信息、猜测、误解及伪装的边界。剧情、对白、基础音色和表格模板均不变；机器检查不能代替独立语义审查和正式交付回执。

部署使用本版本专属的一次性签名恢复目录，完整核对原有项目、导出文件和受保护配置。历史恢复清单不得重新执行。
