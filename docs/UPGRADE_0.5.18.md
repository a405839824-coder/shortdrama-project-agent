# 0.5.18 正式分镜母版音色固定模板

## 变更目标

0.5.18 不增加正式分镜的顶层字段，也不改变十列 Excel。它把原有 `音色` 字段从一行自由描述升级为可验证、可回读、可独立举证的固定多行子模板，并继续保留 0.5.17 的眼部表演和 N−1 相邻镜头连续性门禁。

## 正式母版固定写法

带对白镜按下列顺序填写：

```text
音色：

基础声线：[年龄感、音区、声音厚薄、明亮或低沉、长期稳定特征。]

言语行为：[命令、质问、试探、讥讽、安抚、回避、逼问、恳求、警告、敷衍、认错等。]

当前表达：[一句短而可执行的表层情绪＋必要潜在意图。]

发声方式：
音量：[具体]
语速与节奏：[具体]
呼吸：[具体]
停顿：[具体]
重音：明确落在原文中的“字／词”
尾音：[上抬／下压／截断／发虚／落稳／短收]

禁止语气：[只列本句最可能出现的2—4种错误表达。]
```

`发声方式`只是`音色`内部的空值分组标题，仍禁止作为 canonical 顶层字段。无对白镜固定写：

```text
音色：

无对白，不适用。
```

## 字段职责

- `画面内容`：动作、表情、精确对白、对白发生时点、口型、可见呼吸/停顿、重音期表演、听者错峰反应和镜尾状态。
- `音色`：完整且唯一的发声规格。
- `GPT关键帧生成指令`：继续排除全部音色、发声、对白、口型和音频指令。

旧版发声参数在迁移时只保留到`音色`并标记待修订，不凭空推断角色年龄感、言语行为或潜在意图，也不改写历史工件。

## THG-15

`E-VOICE-001`阻断以下情况：

- 带对白镜仍使用一行自由音色描述；
- 固定标签缺失、乱序、重复、半角冒号或应填值为空；
- 基础声线缺年龄感、音区、厚薄、明暗或长期稳定特征；
- 言语行为、表层情绪或必要意图不明确；
- 重音没有用引号标出，或引号内容不在本镜原文对白；
- 尾音没有明确方向；
- 禁止语气不是2—4项；
- 追加“声音中等清晰、语速从容、关键词加重、尾音随句意收住”等统一中性模板；
- 把固定音色子标签复制进`画面内容`；
- 无对白镜没有明确写`无对白，不适用。`。

## 独立审计 v4

新证书与缓存身份升级为 `semantic-audit-v4-adjacent-continuity-structured-voice`。

- “空间连续”层继续按 canonical 顺序提交全部 N−1 个 `pair:左镜->右镜`。
- “表演链”层继续审查眼球、眼睑、眨眼、重音期不眨和多人错峰。
- “禁项与声音”层必须按 canonical 顺序为每个带对白镜提交 `field:镜头编号.音色`。
- 证书绑定固定模板契约、期望对白镜数、已复核音色字段数、覆盖率、证据 ID、声音层状态和机器 `E-VOICE-001` 数量。

v1、v2、v3 证书保持历史只读，但不能命中新版活动缓存或授权 0.5.18 发布。

## 验证范围

- 27 个 canonical 顶层字段不变；
- Excel 仍恰好十列；
- 正式母版渲染和 XLSX 回读保留完整嵌套音色；
- 顶层旧`发声方式`仍被拒绝；
- THG-01–THG-15、82项 Golden、公共场景、Agent、项目 Agent、MCP、打包与独审契约全部回归。
