# 0.5.19 原文事实转化对白双轨

## 目标

0.5.19 修复“忠实原文被误解为一句不改、叙述性言语行为被机械拍成无声手势”的系统问题。正式分镜母版仍保持 27 个 canonical 字段和十列 Excel，不增加第二份执行模板。

## 两类对白

- `原文直接对白`：继续由 THG-05 逐字逐标点、逐说话人、逐顺序保护。
- `原文事实转化对白`：只在用户授权的集范围内启用；用于原文中的劝、说、称、陈述、解释、指出、承认、要求、反问等可观察言语行为。它不是原文引号内容，必须明确标注为非原文逐字对白。

## THG-16

启用 `source-fact-dialogue-v1` 后，canonical 必须提交 `prevention_evidence.dialogue_adaptation_audit`，并按 Source Ledger 原顺序 100% 覆盖授权集范围内的候选单元。每项至少绑定：

- 逐字原文事实与源文单元序号；
- 对白倾向和处理结论；
- 说话人及其来源依据；
- 改编对白逐字文本与目标镜头；
- 对白承载的事实原子；
- 用户授权；
- `plot_change=false`；
- `new_plot_facts=[]`；
- `entailment_status=entailed_by_source`。

明确说话行为不得再次降级为无声手势。任何未进入原文直接对白保护表的实际对白，都必须逐条进入事实转化台账。

## 音色协同

0.5.18 的固定音色子模板保持不变。THG-15 的重音规则改为“逐字来自本镜实际对白”：

- 原文直接对白镜，重音自然来自原文原句；
- 原文事实转化对白镜，重音来自已经通过 THG-16 证明的本镜改编对白；
- 不允许用“重音必须来自原文”反向禁止合法的事实转化对白。

## 独立审计

新证书与缓存身份使用：

`semantic-audit-v5-adjacent-continuity-structured-voice-source-fact-dialogue`

除 0.5.17 的完整 N−1 相邻镜头组证明和 0.5.18 的逐对白镜音色字段证明外，“源文对白”层还必须按 canonical 顺序提交每个事实转化对白目标镜的 `field:镜头编号.画面内容`。缺镜、重复、乱序、来源不成立、说话人无依据、对白冒充原文或新增剧情事实，均拒绝签发 PASS。

v2、v3、v4 证书保持历史只读，但不能命中新版活动缓存或授权 0.5.19 发布。

## 兼容性

- 正式母版仍为唯一执行母版；
- Excel 仍为十列，不新增“改编对白”执行列；
- 眼球换焦、眼睑变化、眨眼时点、多人数错峰、重音期不眨眼规则不变；
- 旧项目未启用 `source-fact-dialogue-v1` 时保持只读兼容；新生成或重建范围必须显式启用并提交证明。
