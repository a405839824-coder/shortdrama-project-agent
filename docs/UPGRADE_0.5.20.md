# 0.5.20 叙述性会话场景还原

## 修正目标

0.5.19只能可靠拦截带有“说、问、劝”等表层言语提示的叙述单元，无法证明一整场叙述是否实质依靠人物交谈完成。0.5.20改为场景级语义判定：文本即使没有引号或典型言语动词，只要事件依靠人物传达、询问、回答、下令、汇报、辩解、举证或核验完成，就必须还原为对白场景。

## 固定判定

授权范围内每个叙述单元必须按原文顺序选择：

- `叙述性会话场景`：事件主体是人物语言交换；
- `混合会话场景`：对白与可见动作、道具证据共同推进；
- `非会话叙述`：无需人物开口即可完整成立。

每项同时填写交流功能、交流参与方和开口必要性依据。会话或混合会话必须使用`原文事实转化对白`，不得以翻册、递物、点头、对视等无声动作代替。

典型交流闭环包括：问—答、劝—决、令—应、报—听、辩—核、证—判。单镜承载不下时拆镜或重新分配低价值镜头，不得删去交流环节。

## 正式分镜母版

正式母版仍保持27个canonical字段和十列Excel，不新增平行提示词。对白在`画面内容`三阶段时间轴中写明说话者、逐字改编文本、口型同步、重音期表演和听者反应；`音色`继续采用0.5.18固定子模板。无对白镜只有在完成场景语义判定后才允许写`无对白，不适用。`。

## THG-16与独立审计

THG-16不再只从言语动词正则生成候选，而是要求授权范围内全部叙述单元100%进入场景语义台账。会话分类却没有实际对白、交流双方少于两方、缺少交流功能、缺少开口必要性、对白未落镜或新增原文不存在的剧情事实，均触发`E-ADAPTED-DIALOGUE-001`。

新独立审计契约为：

`semantic-audit-v6-adjacent-continuity-structured-voice-conversation-scenes`

“源文对白”层必须：

1. 按Source Ledger顺序提交每个叙述单元的`source-unit:单元ID`，独立复核会话分类；
2. 按canonical顺序提交每个事实转化对白目标镜的`field:镜头编号.画面内容`；
3. 同时验证对白事实、说话人依据、交流功能、交流双方、目标镜头和无新增剧情证明。

生产侧不得通过自行标注“非会话叙述”跳过检查。缺项、少项、乱序、误分类或无声动作替代都会阻断PASS证书。

## 兼容性

- 0.5.19及更早工件保持历史只读；
- 音色固定模板、眼部表演、N−1相邻镜头逐组连续性审计继续生效；
- 公共工具仍为19个；
- 新生成、重建和受影响范围修正统一执行0.5.20门禁。
