# 0.5.51：排除逐镜阅读副本审计

用户明确要求 `*_逐镜阅读` 页不在审计范围。此前导入器仍逐格核对阅读页与 canonical，阅读副本有差异会使整个审计被阻断。

当前共用工作簿解析排除名称以 `_逐镜阅读` 结尾的页，不将其作为母版候选、分镜行、元数据或一致性问题；历史投影、受控恢复和旧母版迁移遵循同一边界。普通读取和批量读取默认选正式母版，显式读取阅读页返回 `audit_included=false`。

审计取正式分镜母版、GPT关键帧、光影、原文依据和绑定 canonical；逐镜字段、相邻镜、八层覆盖和独立审查保持。工具描述、运行时合同、审计义务响应、正式交付合同和技能入口明确排除阅读副本，不用其报错、计分或要求修正。

阅读页继续同源导出，导出器只在生成时检查自己写出的副本。该软件写出检查不算内容审计。正式母版、GPT、K列光影、来源页、审计页和隐藏 canonical 的已有校验保留。文件仍按完整字节签名；修改已签文件后必须重新导入，不能沿用旧文件签名。

验证使用实际 XLSX 字节：阅读页改动/缺失不影响 canonical 或审计义务；阅读页即使伪装母版表头也不能提供替代母版；正式字段与签名页变动仍阻断；默认及显式分页读取标明范围；导出器损坏阅读副本仍由写出自检发现。版本软件检查及部署结果另存发布验收记录，不能替代真实分镜两轮验收或证明首稿准确率。
