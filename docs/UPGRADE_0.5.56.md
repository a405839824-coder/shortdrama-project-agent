# 0.5.56 通用原件审计、投影一致性与逐发言计时

外部原件曾因缺sidecar无法完整进入审计，部分检查又因缺标签提前返回；这会把“调用了检查”误当成“内容已查”。本版为审计保存实际单元格与哈希，保留完整检查义务和四态覆盖，未知不能签发。正式生产仍要求原有证据，不用审计接入口绕过生产门禁。

实际保存的E/F/K、静态初态、环境阶段、光影与本句声法参加核验；复用现有源文和状态投影，不给任何特定剧名、人名或原句添加放行规则。旧签名母版先由冻结的旧版本严格验证原投影，再将真实保存单元格单独送入当前内容审计，旧canonical不变。无引号交流缺证显式保留，旁白不能替角色听取。取消说明文件与注册表之间的强制眨眼冲突。新增通用日间玻璃窗光源类型，区分开闭与玻璃透光，不伪装成纸窗，不放宽夜间或可见光柱限制。

计时保留普通5单位/秒，新增有源成人连续解释6.3候选；逐发言选择由编译、分段、重音尾音及预算/验证共享。视频ASR样本未人工听审、未匹配声线和目标工具，仍为provisional；5.8—6.9仅样本变异参考，不是提速选项。原台词、基声、11列/27字段、4/6/8秒镜头规则与90—180秒范围不变。

首稿冻结后按完整审计N/C/P/F/U计算覆盖率与已审准确率，缺完整证据时准确率未知。机器诊断和软件测试不再被当成首稿内容准确率；历史已交付稿不批量重写。

见[完整使用合同](../skills/shortdrama-storyboard/references/audit_timing_upgrade.md)。验证包括实际旧原件接入、字段篡改负例、缺证/部分审计、变名和不同场景、逐发言真实编译、ASR证据误标拒绝、既有模板/权限/签发/恢复回归。具体执行结果与部署字节、数据保留核验记录在本次发布回执中，不由本文预先宣布通过。开放语义实稿、人工原音和员工双宿主实会话验收与软件验证分别记账。
