# 0.5.22：普通室内清透与室外氛围光分流

## 目的

解决室外有效的雾感、逆光、穿插光线和镜头扩散被机械套入室内后，导致背景泛白、画面雾化、烟感过重、门窗被模型擅自打开或强光落到人物背后的问题。正式分镜母版仍保持 27 个固定字段；`光影、光源来源、光源方向、色温倾向`继续各司其职，不删除光源方向。

## 普通室内默认规则

普通厅堂、卧房、书房、花厅、账房等没有明确烟雾剧情的室内镜头，默认使用：

- `光影`：空气清澈，背景结构与陈设清晰可辨，不泛白、不雾化；人物面部、眼神、手部和关键道具保留真实明暗与材质。
- `光源来源`：按时段选择窗纸漫射自然光、门口环境光、室内灯具或浅墙弱反射；闭合门窗只允许透过窗纸形成柔和面光，不写光束穿窗射入。
- `光源方向`：保留方向判断，写前侧或侧面漫射形成的明暗倾向、暗侧弱补光与向纵深的柔和衰减；不写可见穿插光束。
- `色温倾向`：定性写冷暖关系、肤色和材质本色，不以统一黄、红、蓝覆盖全画面。
- `生成限制`：锁定既有门窗状态；禁止无依据雾、烟、体积光、可见光束、全画面柔焦或镜头扩散、无开口强逆光、背景泛白。

## 允许例外

室内只有在原文或场景事实明确存在香炉、灶烟、失火、扬尘、蒸汽等介质时，才允许烟雾或体积感；必须同时写明具体来源、局部范围、密度克制和背景仍可辨。打开的门窗、天井或真实灯具必须与光源方向一致。仅写“梦幻、朦胧、氛围感”不能构成例外。

室外可在清晨薄雾、雨后水汽、尘土、烟气等真实介质存在，且太阳、天空或灯火方向闭合时使用雾感、逆光、轮廓光、halation或可见体积光。没有介质时，只写空气透视和明暗层次，不写可见光束。

## 验证与审计

- THG-17继续作为统一静帧与光影门禁，错误码保持`E-T2I-001`与`E-LIGHT-001`。
- 普通室内出现肯定式雾烟、可见穿插光束、全画面柔焦扩散、无开口强逆光、背景泛白或光影擅改门窗时阻断。
- “无雾、禁止体积光”等否定限制不会被误判为实际效果。
- 独立审计升级为`semantic-audit-v8-adjacent-continuity-structured-voice-conversation-t2i-indoor-lighting`，其逐镜光影证据契约升级为`t2i-static-observable-lighting-v2`。
- “机位可见性”层仍按canonical顺序逐镜提交四项光影字段，同时复核普通室内清透、门窗状态或有事实依据的局部介质/室外氛围光例外。
