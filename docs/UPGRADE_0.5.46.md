# 0.5.46 单镜规划与模板升级

常规单镜不超过4秒；原来只按容量放行长镜，现在在冻结生产计划和实际重放中共同核对逐镜例外。正式工作簿保留原A—J列位置，新增K列光影，E列去掉四项光影段落及“可见主体：”标签，F列保留静态光影和人物身份。

## 实现

- 一份`shot_design_policy`定义时长分级、例外、景别与输出要求；在线Admin/Producer取得相同合同。4—6秒须有来源、持续内容、实际计划秒数、估计或实测依据、等总时长的≤4秒替代拆法及损失、负载和延长段价值。6—8秒仅固定信息阅读，>8秒重新拆分。
- 每镜`design`绑定景别和切换原因、场景参照物、逐人表演及声音选择；数据留在内部。独立审计义务要求引用实际设计证据并与来源和成品字段比较，不能只提交“通过”。
- 屏幕左中右由同一世界状态及当前摄影机计算；入画主体还绑定有来源/设定支撑的真实场景参照点。切镜不改变世界位置；初态和空白静态段不再输出坐标值。
- 新生产显式选择可见表情姿态，不自动补“平静”；表演变化继续进入既有状态机。声线身份保持，当前表达随情境变化；有限表情姿态库仍须横向审查，不保证自然或不重复。
- 中近景/近景约60%作为整集软目标，特写另计；移除<1秒≥8%、<2秒≥15%的当前硬配额。多人按实际关系取景，解除点位模拟的三人数量拦截；不据此声称复杂遮挡已建模。
- 长对白复用已有原句身份、字符跨度及音频计时链，换机位保持原句与世界状态。不新增第二套对白、光影、母版或语音生成器。

## ponytail优化与兼容

- 复用生产计划、状态机、字段所有权、投影器、阅读页和审计覆盖路径；不增加第三方依赖。
- 新旧R5布局共用投影逻辑，旧十列仅用于匹配原有签名投影；新导出使用`shortdrama-projector/0.5.46`十一列，不新增整份旧投影器副本。
- 旧无侧车十列恢复入口固定引用旧字段列表；历史原件、基线与证书不改。授权规则差异有明确迁移哈希，当前新生产不能回退旧配额或旧模板。
- 当前生成指引、工具说明、模板示例和员工连接指引同步；删去画面示例中的声音属性污染。光影四项和内部人物身份校验保留。
- 补入`production_actions.py`的生产编译依赖指纹，表情/动作实现变化会使旧生成绑定失效。
- 升级恢复使用独立0.5.46签名、单次快照目录，保留原权限、成员连接、Library指针与挂载项目。

## 尚未验收与能力边界

用户明确要求不测试。本次仅作源码、语法、规则/文件差异和发布状态核对；未运行单元、集成、CI、员工生产、分镜实稿或视频测试。新增回归用例保留但不执行。部署完成应另以发布回执记录，本文不是部署凭证。

固定机位及镜间换位沿用现有重放；连续运镜未建模，连续揭示类长镜会返回`not_supported`，须重拆，不能包装为已经支持。文字像素可读性、连续表情质量、人体遮挡与实际声画效果仍须独立实稿/成片验收。4/6/8秒是用户项目规则，不是实测稳定性边界，也不是首稿98%的证明。
