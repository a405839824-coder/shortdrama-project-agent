# 0.5.49 自然时长、真实切点与整集镜数

当一句台词只比4秒多1—2秒，旧例外没有普通完整对白通道，数字拆法也不能证明切镜自然。本版在0.5.48优化代码上增加4—6秒完整短句路径，保留简单表演，拒绝用空等、加速或虚构情绪换取延长。

新生产使用production_plan v3、shot_design v2。每镜cut_anchor必须指向真实边界上的声音/动作或实际换场；候选切点绑定当前镜头内部事件或台词字符，不再要求编造“几秒＋几秒”。没有合适切点可明确说明，仍需独审。字符与内部时间位置不冒充实际音频对齐。

复用既有计时、世界状态、来源保护、直接canonical门禁与独立审计。整集按实际时长生成镜数、均值、时长分布和重复切镜理由；平均3—4秒是预算假设，120秒30—40镜等范围不会自动判错或要求凑数。整批首条统计审计必须读取实际节奏证据，后续页继续携带所需观察引用。

同框人数不直接等同于复杂度；辅助表情不增加主要动作主体数，但实际多发声任务与复杂接触仍受限。原对白、90—180秒、来源因果、十一列母版、字段归属、权限与历史证据保持。6秒以上人物对白、连续运镜和J/L跨镜音频仍未放开。

本版按用户要求不运行测试。保留最小回归文件并同步现有夹具，未执行。语法/规则视图/发布字节核对属于静态及部署检查；真实内容、音频、自然度、员工窗口和首稿95%/98%未验收。源码修改、部署成功与功能通过分别记录。
