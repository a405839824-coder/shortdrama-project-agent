# 旧工作簿母本绑定：解析修复与待实施的受控迁移

状态：解析修复候选；迁移入口尚未实现。本文件不授权上线，不构成分镜审计证书。

## 已确认的阻塞

当前服务要求没有绑定 canonical sidecar 的工作簿先生成新的 `PENDING_AUDIT` 后继，再执行独立审计。读取 Excel 中的正式母版并不等于完成这一绑定。

存在两个相互独立的问题：

1. `_parse_function_scene_cell` 只识别带标签的组合列，不能读取旧表明确写出的 `功能 / SCENE-ID`，导致所有镜头的场景 ID 为空。
2. 当前没有专门的旧工作簿迁移入口；普通 `storyboard_regenerate` 在项目存在待审交接时被 `independent_audit_pending` 拒绝。控制状态迁移和旧交接恢复工具均不负责创建缺失的 canonical 绑定。

## 本补丁实际实现

仅扩展组合列的只读解析：保留原有带标签格式，额外识别唯一的空白包围 ASCII `/` 分隔符及显式连字符或下划线 ID。功能正文中的全角 `／` 保留；缺失、自然语言、路径及多个分隔符不猜测场景。

本补丁不改变生产待审门禁、权限、sidecar 存在标志、源文权威、预检要求、独立审计签名和证书缓存。旧工作簿仍不能直接签证。旧提取缓存也不会因代码升级自动变成新解析结果。

## 迁移还需实现的内容

迁移必须作为经过审批的新能力实施，不能把普通生产、来源导入或审计工单伪装成另一个操作来绕过当前限制。

| 阶段 | 必须绑定或验证的事实 | 失败行为 |
|---|---|---|
| 只读预演 | 当前项目、登记能力缺口、原始输入 artifact、文件 SHA、来源工单、确切集数和全部镜头 | 返回具体原因；不写分镜、后继、证书或交接 |
| 原件重解析 | 从已锁定原始 XLSX 读取，不能沿用不兼容的提取缓存；保留公式及缓存值各自的身份 | 未支持公式、缓存与正文不一致、字段歧义时阻塞 |
| 无损核对 | 27 个语义字段、镜头顺序、台词原字与标点、多行声线、转场文字、源文支撑和分集累计时长 | 任何非授权语义变化时阻塞，不静默规范化 |
| 迁移授权 | 独立的迁移工单、当前计划 SHA、明确批准、一次性领取与 CAS | 不允许拿修复或只读身份提交；不清除其他待审记录 |
| 生产预检 | 补齐真实的来源权威、替换方案映射、预防证据、逐场景预检与全量零问题预检 | 保留失败证据，不生成伪造的零问题预检 |
| 新版绑定 | 原件不变，创建 canonical、投影工作簿及 `PENDING_AUDIT` 后继，绑定原件 SHA 与迁移计划 | 原子提交失败则可恢复；不得留下已签未提交的半成品 |
| 完整独立审计 | 独立工单、精确新 canonical/工作簿指纹、八层语义证据、完整机器校验和全部邻镜范围 | 真实签发当前通过或失败结果；生产预检不能代替结论 |

读取阶段还需要检查既有解析行为：累计时长可能保留为公式字符串，多行音色的空行会合并，生成限制和转场标点可能被旧迁移规范化。它们不全是剧情错误，但不能把经过这些变化的结果声明成与原件逐字段完全一致。应保留原文层及公式层证据，给出明确的转换清单。

## 实施验收门禁

- 合成工作簿测试覆盖组合列两种格式、缺失和歧义、多个对白及声线段；不把真实项目正文提交为代码测试数据。
- 核对新解析器与旧解析器的字段差异仅涉及本次授权的功能和场景拆分；另行记录旧解析本来存在的差异。
- 保持没有 sidecar 的工作簿不能直接独立审计、不能创建证书或交接的回归断言。
- 迁移预演必须无项目内容副作用；执行必须校验原件、计划、授权和当前项目版本。
- 在其他批次仍待审的测试项目中，仅专门批准的迁移可创建自己的新后继；原有普通生产门禁保持生效，其他交接与证书逐字节保持不变。
- 故障注入覆盖提交前后、指针冲突、重复执行、过期计划及进程重启；不得重复签发或丢失历史。
- 运行核心规则、服务测试、XLSX 绑定、独立审计、存储、HTTP/stdio 和结构检查；测试通过后再请求正式功能启用批准。
