## 0.5.4 已固化契约

- 模型只提交一份 27 字段 compact canonical；`正式分镜母版`和`GPT关键帧生成指令`只在导出时从同一 canonical 确定性投影。
- 正式 XLSX 固定十列；第五列为`正式分镜母版`。每镜`生成限制`、正式母版和 GPT 投影均明确且只保留干净的`9:16竖屏`。
- 导出前执行 THG-01–THG-12：画幅、转场去重、静态关键帧、无跨镜代指、对白/说话人精确覆盖、可见人数、单机位/单核心阶段、起始状态、道具唯一持有人、时长容量、canonical/XLSX 反向一致性和审计权限。
- 正式母版和 GPT 投影禁止`BGM`字面量；负面音频约束统一投影为`禁止额外配乐`。对白、匾额和可见文字中的“音乐”不作为主动配乐指令误报。
- GPT 关键帧只读取静态白名单；时间码、运镜、转场、对白、口型和音频过程零残留，同时保留`【参考图锚点】`、`【可见文字】`和`【匾额】`等视觉信息。
- canonical、投影、XLSX 侧车和多行字段按 UTF-8 NFC + LF 归一化校验；当前侧车不可降级冒充 0.5.0，完整 0.5.0 文件仍由冻结投影器只读验证。
- 生产预检失败不导出、不写 artifact、不消耗版本、不建 handoff。生产通过只写`PENDING_AUDIT`，不得预填 PASS、零问题或审计 trace。
- 独立审计生成签名 overlay 后继工件，不就地改写生产工作簿。显式强制复审发现新 FAIL 时，撤销旧 PASS、latest 和对应工单状态，同时保留同一权限绑定下的证书历史。
