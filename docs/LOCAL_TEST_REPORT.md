## 用户访问契约

- 同一认证用户命名空间中的任意 ChatGPT 窗口均可创建或继续生产、独立审计、修正及复审工单；用户窗口不再分配角色，也不需要执行角色接续或权限恢复。
- 每张工单仍由服务端签发独立的 authority root、window binding 和 actor binding。用户可以在同一聊天中依次生产、审计和修正，但生产证据不能冒充独立审计结论。
- 待独立审计仍暂停下一批生产；当前任意窗口都可直接完成该审计。这是质量流程顺序，不是窗口权限。
- 跨认证用户命名空间、缺少可信云会话、无签名修复包、无明确修正授权、证据或内容漂移仍失败关闭。
- 0.5.13 及更早的窗口绑定工单保持原字节与原验证语义；公共 MCP 从 0.5.14 起默认创建窗口无角色限制工单。
- 公共工具保持精确 19 个，不新增权限管理工具。
