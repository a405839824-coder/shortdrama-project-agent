# 0.5.65 — 生产状态、证据衔接与可验证的诊断

此前多次修正规则后，真实草稿仍暴露声线规则分歧、v3 计划与旧表演证据脱节、动作文字与实际状态不一致，以及上游失败引出的下游误报。本次在实际生成和校验路径修复这些接口，不把减少机器提示等同于分镜质量提高。

## 本次变更

- 以规则 registry 的完整子句作为基础声线五要素唯一口径；成人、儿童、明确未知年龄和有界哭喊表达共用规则。保留既有合法简写、既定声线例外及动作污染拦截。
- 从冻结 v3 计划、真实事件和起止状态派生 `performance-evidence-v1`。只有完整 derivation 重放且逐字匹配才能替代重复手填的旧表演链；语义结论保持 unknown，独立审计仍必须执行。
- look 文本按逐 tick 实际头向和视线变化投影；同坐标异目标身份不再凭标签虚构转头。切镜提示绑定经过验证的剪辑锚点。
- 早期几何检查覆盖同场全部人物的眼、手和 ground 点。未重放的后镜只能报告 initial-world 条件快照，不能冒充实际起始状态或完整人体遮挡证明。
- 来源编译失败时，依赖的冻结计划检查显示带原因的 not_checked；首镜衔接、各条声线和表演声明等可独立判断的问题一起返回。
- 新增有限的双人搂抱、抱起、同场抱行、真实通道跨场及未离地搂抱解除；保留两个人物身份、逐 tick 接触和障碍检查。新增不透明腰套的初始容纳与随身传播。
- 发布恢复采用新的 0.5.65 单次签名快照；后台副本清理在恢复和显式核验期间暂停，避免核验前改变已恢复文件树。旧升级记录、账户角色及管理员互读策略保持原样。

## 能力边界

施救手法、吐水、远程抱人瞬移、放下被抱者、容器插入/取出仍不支持。有限 landmark 模型不是生物力学、承重或完整网格遮挡证明。没有实际生图、视频或音频测试时，不报告这些媒体的生成失败率。

## 验收方法

1. 最小正反例验证真实执行与拒绝路径，保留升级时发现的兼容退化。
2. 原失败稿逐字保留。原运行指纹失效单列；仅重绑定运行指纹的派生副本明确记录差异，不冒充原稿未改的完整服务回放。
3. 从未参与修复的第 45、60、78 章选段重新生成，先冻结首稿再读诊断，由独立审查者分类。组件通过、场景通过及实际媒体效果分别统计。
4. 发布以完整回归、代码复核、当前文件树备份及线上版本/恢复核验为准。本说明本身不构成已上线证明。
