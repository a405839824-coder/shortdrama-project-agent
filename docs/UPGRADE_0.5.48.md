# 0.5.48 代码优化与数据保全

本版发布已完成测试的代码优化，保留 0.5.47 的生产规则与十一列正式母版。

- Library 重挂载保留未同步的来源和审计文件；挂载、卸载、导出使用同一项目锁。
- 重复表头不再覆盖字段；诊断分页在预算耗尽时保留续读位置；混合新旧对白保留原顺序。
- 旧格式审计 JSON 片段保留正文空白，继续检查长度、重复项、顺序与证据精确匹配。
- 删除重复编译、哈希、拷贝和无效计算，统一原子写入；缓存结果保持隔离，检查器指纹读取当前实际文件内容。
- 打包提前排除无关目录，修正 PowerShell 失败码和云端地址校验，移除重复测试发现。

优化候选完成 1669 项独立测试：Windows 下 1667 通过，2 项因符号链接权限及 POSIX 文件名限制跳过。STDIO、HTTP、完整运行时自检、规则一致性和源码包检查通过。发布提交的 Linux CI 与线上切换证据另存于部署记录。

历史反例夹具迁移见 [迁移说明](COUNTEREXAMPLE_FIXTURE_MIGRATION.md)。历史规则定义、阈值、已生成分镜、审计历史和权限边界保持不变；软件检查不能代替实际内容的独立审计与正式签核。

部署仍使用现有 Railway 服务、域名和持久卷。切换前停止外部写入并备份挂载运行态；0.5.48 启动时只消费本版签名清单一次，核对文件哈希、角色、成员连接、Library 指针及签名密钥后才监听。已消费的升级快照不会在后续启动时重放。
