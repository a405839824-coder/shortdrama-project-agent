# 0.5.31：自然画面正文与内部计时

此前模板、生成器和修正提示要求把三个数字阶段写进画面内容，导出会再次携带这些时间码。本版按用户要求让画面正文只展示自然动作和对白，数字制作时点独立保存并与正文绑定；正文变化使旧计时失效，不能因隐藏数字而放过超时或声画冲突。

## 发布范围

- 新生成的画面字段去掉“【0.0—0.4秒】”“于0.4—3.4秒”等制作计时；27 个正式字段、十列输出和独立时长/累计时长保留。对白及画内文字中的真实时间、剧情日期按原内容保留。
- 两处正式母版拼接共用同一展示函数；内部 `picture_timing` 只保存可验证的计时注释及其位置，并绑定正文摘要。拒绝旧绑定、非法偏移、夹带动作或把计时插入对白等伪造记录。
- 内部继续验证对白容量、动作时间、眨眼和发声事件；计时修正不得把时间码补回正文。旧带时间码的稿件仍可读取，新导出使用自然正文，历史冻结规则及签审计证据不覆写。
- 新导出的 canonical sidecar 保留内部计时以供无损回读；没有 sidecar 的旧工作簿按其实际单元格恢复，不猜补缺失的计时数据。
- 补充“上一个镜头”“上个镜头”等跨镜代指词形；明确角色对白和已识别的当前画内文字按字面内容处理，带引号的制作指令仍受检查。
- 规则注册源、生成视图、字段说明、示例与修正提示同步。保留 0.5.30 的管理员/员工权限及成员隔离，不改变 Auth0 或项目存储配置。

## 尚未覆盖

本版不包含用户完整 R5 逐镜阅读卡片渲染器，也没有解决所有制作目的混写、缺失人物状态及自由输入绕过受约束生成入口的情形。明确语法识别不能代替来源真实性、字段用途及剧情语义判断；软件通过不代表首稿达到 98%。

## 验证与上线

候选的 109 项相关回归已通过，覆盖正文展示、作者序列化、母版投影、字面内容保护及旧工作簿迁移；bootstrap 分组检查、HTTP/stdio 和原件回读已通过。发布版本仍须完成完整 Linux CI、包检查及线上验收。第一份完整本地回归发现历史夹具依赖当前导出格式后中止，随后固定历史输入并通过相关测试；不能把中止记录算作全量通过。

上线时使用通过 CI 的确切发布树，保留原持久卷、成员配置和签名密钥；核对 `/health` 与认证后的工具版本为 0.5.31，并在部署代码中验证去时间码导出及内部计时回读。正式发布结果以对应 PR、CI 和部署记录为准。
