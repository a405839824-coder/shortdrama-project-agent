# 字段内容合同

由 rule_registry.json 生成；不得单独编辑。

合同：storyboard-field-content-v1

生产决定按字段类型输入，母版/GPT由程序投影。历史原件保留；结构和已支持错列检查不能自签来源或表演语义。
字段正文不得嵌入其他字段或音色子项标题；真实对白和当前可见道具文字保留字面含义。
机位、基础声线、当前表达、环境音效和光影按已登记完整子句检查；合法但未支持的句式返回not_supported，不静默删除或猜改。其余字段继续执行结构化生成、所属角色和独立语义核对，不能宣称任意自然语言已全自动判定。
当前结构化生产在实际发声期间逐0.1秒核对可见睁眼视线；摄影机方向5度锥内或缺明确视线均不能通过。这是保守几何余量，不是实测视觉阈值，最终眼神自然度仍须独审。

| 字段 | 允许内容 | 关联与禁止内容 |
|---|---|---|
| 镜头编号 | 程序分配的本镜标识 | 不接收自由备注、另一套镜号；对应稳定镜头身份 |
| 时长 | 本镜执行时长数值 | 不接收剧情解释；对白、动作、心理音轨和依赖顺序实际可容纳 |
| 累计时长 | 同集按序累计结果 | 不由模型手算，不跨集串算 |
| 功能类型 | 已确认叙事节拍中的本镜作用 | 不写长篇剧情、审核意见；不得借填功能新增剧情 |
| 场景连续性ID | 已登记场景状态标识 | 不用自由文字代替；换场／跨时空须有对应转换依据 |
| 镜头类型 | 景别、构图和单镜拍摄类型 | 不写动作过程、第二机位、剪辑指令；与实际入画范围相符 |
| 可见主体 | 本镜视场内的具名人物、身体局部或道具 | 不列仅被提到的人；声音来自画外不等于声源可见；明确入画时段，GPT 只取起始可见集合 |
| 空间站位描述 | 起始时各对象相对场景锚点的位置、朝向和空间关系 | 不写走近、坐下等过程，不写未来落点；由同一场景和初态数据生成 |
| 起始状态 | 起始时刻的姿势、表情、视线、手部和道具状态 | 不写下一步动作／未来结果；不写“承接上镜”“保持原状态”，须展开具体事实 |
| 机位 | 摄影机起始位置、高度、朝向、必要镜头参数、焦点对象与部位 | 不写演员动作、声音或剧情结果；焦点须在此刻存在且具备所需可见性，不能对焦未来文字／转身后的眼睛 |
| 运镜方式 | 摄影机及焦点随镜内事件的运动方式、轨迹和终点；无运动时写固定镜头 | 不写人物走位正文、对白或隐藏切镜；起点绑定机位，终点绑定已确认拍摄决定 |
| 画面内容 | 有依据的可见动作、表情变化、视线和道具变化，按自然先后关系表达；准确对白及其说话人／口型事件 | 不写摄影操作、声线参数、光源配置、制作目的、跨镜省略、全局生成禁令或审计结论；无数字制作时间标记；原句中的真实时间保留 |
| 音色 | 发言人的稳定声线及当前对白的发声指导，严格按第 5 节子项组织 | 不放摄影、可见动作、新增剧情或改写后的台词；每段绑定说话人和实际对白 |
| 心理音轨 | 有依据并获准的内心独白；以及既有规则允许的客观旁白，明确类别、所属角色／叙述者、原句和音轨属性 | 不把客观旁白冒充人物所知；不让心理话变成嘴部对白。现有“不驱动口型、不生成字幕、不计角色对白”等局部音轨属性留在本字段，不扩成全局杂项 |
| 环境音效 | 场内声源、具体声音、远近层次及相对事件关系 | 不写人物主对白、音色指导、配乐或摄影；声源可在画外，不能据此添加可见物体 |
| 环境动态 | 背景人物／环境物体的可见运动 | 不写运镜、声音、主角核心动作；不得无依据补风雨烟雾；对应环境事件状态 |
| 光影 | 当前光源作用于具体主体／材质的明暗、投影和反射效果 | 不写人物心理、剧情目的或无依据雾化；不在此重复编一套光源位置和色温 |
| 光源来源 | 已登记光源的种类、位置及真实开启／遮挡状态 | 不编造灯、窗或天气；不将“紧张、压抑”当作光源 |
| 光源方向 | 光线相对世界、主体与画面的入射方向 | 从光源、机位和主体朝向推导；不照抄已失效的画面左右，不混入声线和动作 |
| 色温倾向 | 光源组合所支持的冷暖及主次关系 | 不写照射方向、灯位或情绪；沿用当前定性表达规范，不增加被禁用的 K／开尔文数字 |
| 生成限制 | 项目允许的画幅、额外人物、字幕水印、额外配乐等生成政策 | 不接收剧情、起始状态、摄影参数或审计声明；按视觉／音频等适用对象分类，供不同输出选取 |
| 转场类型 | 已登记的剪辑／转换类型 | 不写第二段剧情；须与本镜结束和目标镜关系匹配 |
| 切镜/转场提示词 | 具体切点、结束条件、确有依据的目标画面关系 | 不复制完整动作段，不用“承接上一个镜头”代替事实，不追加机械等待或新剧情 |
| 参考图锚定 | 真实素材绑定、对象、版本和用途；或有设定依据的文字造型描述与绑定状态 | 不虚构图片 ID、附件已核实结论；文本造型事实与“未附图”等状态分别存储 |
| 覆盖原文 | 原文位置清单 | 不写剧情梗概、通过率、是／否；定位须能回到锁定来源 |
| 原文依据类型 | 已登记分类、实际组合与授权依据 | 不将推断记成原文直述，不替用户新增改编授权 |
| 原文支撑句 | 与来源位置一致的逐字文本 | 不允许补写、润色或删否定／条件；不能拿模板样文冒充本集依据 |

## 音色子项

| 子项 | 允许内容 | 禁止内容 |
|---|---|---|
| 基础声线 | 来自人物声线档案的年龄感、音区、厚薄、明暗、长期稳定特征 | 临时情绪、语速、动作、机位；不得无依据推测声线 |
| 言语行为 | 本句的询问、请求、拒绝、警告等已确认话语行为 | 走动、皱眉、运镜、未来剧情 |
| 当前表达 | 本句可执行的声音情绪和有依据的表达意图 | 长篇心理分析、隐藏剧情真相、身体动作、摄影指令 |
| 发声方式 | 只作以下六项的分组标题 | 标题后不另写自由正文 |
| 音量 | 本句响度及必要的相对变化 | 音区、身体动作、环境声设计 |
| 语速与节奏 | 本句快慢与节奏组织 | 镜头时长、制作时间码、停镜／运镜安排 |
| 呼吸 | 与本句发声相关的气息支持、气声或换气方式 | 胸口起伏等可见动作正文、人物新病症或环境风声 |
| 停顿 | 绑定实际词句或事件的必要语句停连 | 为凑镜长机械等待；不凭空增加对白或镜尾停顿 |
| 重音 | 实际对白中可定位的原词／原片段及其重读方式 | 改写原词、引用另一人物对白、追加动作和机位 |
| 尾音 | 上抬、下压、截断、发虚、落稳、短收中的适用收尾方式 | 自由续写另一句台词或剧情 |
| 禁止语气 | 针对本句的 2—4 项错误发声方式 | 额外人物、字幕、水印、拍摄位置等全局或视觉限制 |

## 其他历史问题的针对方案

- historical_scope：EP32-38; 229 first-draft and 109 revision category-shot-version units; not unique shots or future probabilities
- state：single authoritative world, typed event effects, complete dependency propagation and start/end comparison
- geometry：derive visible set, frame crop, world-to-screen position and light direction from the same camera; mesh occlusion remains separately reviewed
- performance：explicit gaze endpoints, unique event occurrence, listener prerequisites and source-grounded expression; correct field labels do not choose acting decisions
- audio：bind speaker/utterance/voice profile, real complete emphasis units, mouth state and independently calibrated timing
- source：coverage of identity, negation, condition, chronology and causality; citations cannot substitute for actual scene presentation
- acceptance：freeze real first attempts and score source/semantics/state/availability separately; software tests do not prove 98%
- production_policy_ref：runtime.production_prevention_policy
