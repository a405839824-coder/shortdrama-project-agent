# 小说章节到分镜前置规划门

适用于小说、长叙事、章节文本或连续剧情直接转正式分镜。目标不是逐句拍摄，而是在不丢失核心剧情、因果、人物变化和关键对白的前提下，把完整章节转换为可执行节拍与镜头。

## 目录

1. 入口与完整读取
2. 章节边界与剧情地图
3. 内容价值与取舍
4. 对白、人物状态与认知
5. 改编预算与节拍规划
6. 镜头生成约束
7. 视觉化许可
8. 覆盖审计与停止条件
9. `source_ingestion`证据契约

## 1. 入口与完整读取

- 生成正式分镜前必须完成整个授权章节的读取与汇总。禁止读一段、生成一段、再读下一段。
- 长章节可以分块读取，但分块仅用于提取。所有分块必须读完并合并为同一章节地图后，才能规划节拍或镜头。
- 记录`chapter_id`、`chunk_count`、`chunks_read`与`complete_read=true`。`chunks_read`不足时停止在入口门。
- 同时读取可获得的上一章节结尾和下一章节开头；若确实不存在，写“不适用+原因”，不得猜测。
- 章节存在矛盾、指代不清、缺页或关键上下文缺失时，标记`uncertainty_status=unresolved`并停止生成，不得自行补剧情。

## 2. 章节边界与剧情地图

完整读取后先建立：

- 章节目标与观众应获得的信息；
- 有序核心事件列表；
- 原因—行动—结果因果链；
- 铺垫、冲突升级、高潮、回报或反转、结尾状态；
- 上章终点、本章起点、本章终点、下章起点；
- 每个关键人物的开始状态、触发事件、结束状态；
- 人物已知、未知、刚获得的信息及禁止提前表达项。

事件不能只写摘要。每个事件必须有稳定`event_id`、源文单元、价值等级、因果位置和目标节拍。

## 3. 内容价值与取舍

S/A/B/C只作为最终等级，不可替代判断过程。每个源文单元至少评估：

- 因果必要性；
- 新信息与身份信息；
- 人物目标、认知、关系或状态变化；
- 冲突升级、反转、爽点、回报与章节钩子；
- 情绪铺垫与情绪兑现；
- 时间、空间、气氛、伏笔和人物生态等电影功能；
- 与其他内容的重复度；
- 制作可行性。

最终处理只允许：`保留`、`合并`、`压缩`、`移动`、`删除`。

- S级：主线、身份、关系变化、冲突升级、反转、爽点、关键决定，必须保留。
- A级：人物状态变化、重要心理与关系铺垫，重点表现或有证据地压缩。
- B级：重复说明和普通交流，可以合并或压缩，但不得破坏因果、动机或角色声音。
- C级：仅是删除候选，不得自动删除。环境描写可能承担时空、情绪、伏笔、转场或人物生态功能。
- 删除必须有用户授权或可核验的冗余证据；若删除单元承担电影功能，还必须写明该功能被哪一节拍或镜头承接。
- 所有非删除单元必须映射到有效节拍；所有处理必须写理由，形成无损取舍台账。

## 4. 对白、人物状态与认知

逐行识别对白功能。以下任一命中即进入保护清单：

- 新事实、身份或线索；
- 认知改变；
- 关系确认或变化；
- 决定、承诺、威胁、拒绝或立场；
- 冲突、反转、爽点、回报或结尾钩子；
- 因果桥；
- 独特人物口吻或具有后续回收价值的句子。

保护不等于逐字照搬。压缩、合并或改写必须保留说话人、核心信息、关系力度、因果作用和人物声音，并映射到目标节拍。对白总时长按2.8个汉字/秒加停顿预算计算。

每个关键人物建立：

- 开始认知、情绪、目标、关系阶段；
- 触发事件及其可见影响；
- 结束认知、情绪、目标、关系阶段；
- 本章未知信息与禁止提前表达项。

## 5. 改编预算与节拍规划

镜头数量不是先验固定值。先锁定：

- 目标成片时长；
- 保护对白所需时长；
- 必须可见的行动时长；
- 建立空间与必要转场时长；
- 高潮、反转和结尾钩子的留时；
- 合理镜头数范围。

若对白、动作与转场最低时长之和超过目标时长，先重新取舍或扩大时长，不得把过量内容塞进镜头。

采用三层转换：

`源文单元 → 剧情事件/节拍 → 正式镜头`

每个节拍必须有核心阶段、事件ID、源文单元ID、入口状态、出口状态、目标时长、镜头数范围和叙事功能。铺垫不得耗尽高潮预算。

## 6. 镜头生成约束

- 禁止“一句原文等于一个镜头”的机械拆分。
- 单镜只承担一个核心叙事或情绪阶段、一个视角和一个摄影机位置。
- 同一核心阶段内允许连续动作链：起始状态→动作→可见反应→情绪结果。
- 一个镜头可以同时携带相互依赖的动作、信息和情绪，但不得出现第二个独立转折、跨时空跳跃或隐形切镜。
- 信息不足时合并；出现多个独立阶段、多个机位或不可执行负载时拆分。
- 先完成节拍级预审，再生成镜头；不得把末端审计当作前置规划替代品。

## 7. 视觉化许可

允许增加但不得改变剧情：

- 与原文状态一致的眼神、呼吸、微表情、手部与身体连带；
- 已有道具和环境的可见反应；
- 机位、景别、运镜、光影、色彩和声音设计。

条件允许：

- 将内心状态外化为不改变事件、决定、动机和结果的微动作；必须写源文依据和`plot_change=false`。

禁止未经授权增加：

- 新事件、新冲突、新角色行为；
- 新决定、新动机、新信息或新结果；
- 为“视觉效果”增加摔倒、打翻、追跑、攻击等原文不存在的情节。

## 8. 覆盖审计与停止条件

生成前预审和生成后复审都必须达到：

- 核心事件覆盖率100%；
- 因果链覆盖率100%；
- 关键人物状态变化覆盖率100%；
- 保护对白覆盖率100%；
- 源文单元处理率100%。

复审还检查：章节目标、高潮权重、人物认知、场景衔接、上一/下一边界、镜头负载和是否新增原文外剧情。任一指标不足100%或存在未解决歧义时，状态为`fail_current`，不得进入生产输出。

## 9. `source_ingestion`证据契约

小说章节转分镜时，在正式JSON顶层加入：

```json
{
  "source_ingestion": {
    "mode": "chapter_to_storyboard",
    "chapter_id": "CH-001",
    "complete_read": true,
    "chunk_count": 1,
    "chunks_read": 1,
    "boundary_context": {},
    "chapter_goal": "",
    "events": [],
    "causal_links": [],
    "character_state_changes": [],
    "source_treatment_ledger": [],
    "protected_dialogue": [],
    "adaptation_budget": {},
    "beat_plan": [],
    "visualization_license": [],
    "new_plot_events": [],
    "uncertainty_status": "clear",
    "coverage_metrics": {}
  }
}
```

`source_ingestion`只在`mode=chapter_to_storyboard`时触发本门禁；已有非章节分镜继续使用通用R10证据。正式镜头仍必须进入原有`prevention_evidence.source_ledger`，本章台账不能替代镜头级源文映射。
