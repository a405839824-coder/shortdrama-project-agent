# 公共场景人物与环境音生态门禁

适用于街道、闹市、市集、商街、巷道、城门、码头、驿站、茶馆、酒楼、餐馆、客栈大堂、庙会、店铺公共区、衙门外、宫门和其他具有公共流动属性的场景。该门禁同时约束正式分镜、关键帧可见声源、Seedance 2.5独立正式执行分镜和镜间连续性。

## 1. 触发与例外

公共场景默认必须存在普通人物与可听环境生态。不得用“人群”“路人”“环境声”“街道嘈杂声”作为占位词通过。

只有剧情明确要求空场时才可豁免。豁免必须同时写出：

- 可见空场状态，如空街、闭市、店门紧闭、人群已撤离；
- 可核验原因，如宵禁、封锁、疏散、戒严、灾后、深夜停业、危险预警或用户明确要求。

仅写“无人”或“空街”而没有原因，仍然失败。

## 2. 普通人物视觉生态

每个非豁免公共场景镜头必须按地点、时代、时段、天气和剧情填写：

1. **密度**：稀疏、中等、密集或明确人数；密度由场景事实决定，不为热闹感任意加人。
2. **角色**：使用地点匹配的普通人物，如行人、摊贩、顾客、脚夫、车夫、伙计、守卫、香客、船工；禁止现代服装、现代职业和时代错位道具。
3. **错峰动作**：不同人物独立完成穿行、交谈、挑选、驻足、避让、叫卖、搬运、查验、上香、端菜等动作；禁止同步走动、复制脸、整齐转头、集体看镜头或无剧情原因围住主角。
4. **空间层次**：建立镜、全景、远景至少写明两层普通人物分布；中近景和特写至少保留一个可读的中景、远景或背景公共活动层。普通人物不得遮挡主角眼神、关键动作或必要出口。
5. **连续性**：同一场景相邻镜保持人流密度、流向、主要背景角色和出入口逻辑。密度变化必须用涌入、散开、疏散、离开或时间推进在画面中交代。

正式分镜的`人物调度`、`画面内容`、`环境动态`与Seedance批次的`起始画面`、`动作过程`、`结束状态`、`环境动态`必须使用同一套公共人物事实。

## 3. 环境音效强制层

公共场景声音必须来自画面内可见声源或被明确标注为可信画外声源。每个镜头按摄影机位置建立近、中、远声场：

- 建立镜、全景、远景：至少三类具体声源和近/中/远三层声场；
- 中景、近景、特写：至少两类具体声源和两层声场；
- 带主角对白：环境底声必须明确压低、退至底层或不遮盖对白，主角台词最清晰。

场景声源参考：

| 场景 | 可选具体声源 |
|---|---|
| 街道、巷道 | 脚步、衣料、木轮、马蹄、担子或推车声 |
| 市集、商街 | 错落叫卖、含混人声、货物碰触、铜钱、算盘、秤砣 |
| 茶馆、酒楼、餐馆 | 食客低语、碗筷杯盏、伙计脚步、后厨案板或炉火 |
| 城门、驿站 | 守卫口令、查验、木轮、马蹄、城门木栓或甲片 |
| 寺院、庙会 | 远钟、木鱼、风过树叶、香客脚步、含混人声 |
| 码头、渡口 | 水声、橹声、缆绳、脚夫搬运、货物落地 |
| 雨雪公共场景 | 雨滴、檐下滴水、踩水、踏雪、风吹衣摆 |

“环境声”“人群声”“闹市声”“街道嘈杂声”不能单独作为完成描述。禁止汽车喇叭、手机铃声、电子提示音、广播、扩音器、警笛、发动机、地铁或电车等时代不符声源。

匿名路人、百姓、食客或摊贩不得获得清晰完整对白，以免随机口型和字幕污染。使用“含混低语”“错落叫卖”“远处非语义人声”即可；只有原文或任务明确授权的具名人物台词才进入`台词`字段。

## 4. 画面与声音一致

- 马蹄、车轮、碗筷、叫卖、钟声等可识别声音，必须在画面中存在对应人物/道具/地点，或明确写成远处、画外、门外等可信声源。
- 关键帧没有声音字段，但必须能看见足以支持正式音效的动作或声源。
- Seedance批次`声音`必须复现正式镜头的具体声源和声场层次；`环境动态`必须独立写明公共人物角色与动作。
- 同场连续镜允许因景别和机位改变声音远近，但不得无画面原因更换整套环境底声。
- Seedance阶段继续禁止BGM；环境音效不是BGM，可在生成阶段保留。

## 5. 硬错误码

- `E-PUBLIC-ECOLOGY-001`：公共场景无普通人物生态、生成限制排除了必要普通人物，或空场无有效原因。
- `E-PUBLIC-CROWD-001`：只有泛称人群，缺密度、地点角色、错峰动作或空间层次。
- `E-PUBLIC-AUDIO-001`：环境音缺具体声源/声场层次，或对白镜未做声音避让。
- `E-PUBLIC-AVSYNC-001`：声画来源不一致、匿名群演清晰说话、出现时代错位声源，或Seedance批次未独立复现人物/声音生态。
- `E-PUBLIC-CONT-001`：同场连续镜的人流密度无画面过渡地跳变。

任一错误未修复时，正式分镜、关键帧批次和Seedance 2.5生产批次均不得进入下一阶段。

## 6. 最小合格示例

> 画面内容/环境动态：古代市集，中等人流；前景两名行人错身避让，中景摊贩分别招呼顾客、整理货物，背景脚夫推车穿过街口，动作节奏错开，不看镜头且不遮挡主角。

> 环境音效：近处衣料和脚步，中层含混交谈与零散货物碰触，远处错落叫卖和木轮声；主角开口时环境底声压低，不遮盖对白。

> Seedance声音/环境动态：从零写明同一组角色、动作、近中远声源和对白避让，禁止用“同上”“承接上一镜”代替。
