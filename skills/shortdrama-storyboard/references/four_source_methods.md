### 眨眼最终规则

现行规则以注册表THG-13为准：允许持续同一视线、自然静止和零眨眼，不设最低配额，也不强制添加换焦、眼睑或呼吸作为替代。已写眨眼须核实际可见性、闭眼状态、重音保护和错峰；3–5秒0–1次、>5–10秒0–2次只是上限。静帧保留真实起始眼睛状态，不写眨眼过程。

## 景别与光影

默认注意力链：远景交代环境 → 中景承接动作 → 近景传递情绪 → 特写放大有剧情功能的细节。

| 景别 | 功能 |
|---|---|
| 远景 | 交代环境、时间、空间关系和场面 |
| 中景 | 承接动作、站位和人物与环境关系 |
| 近景 | 传递情绪、眼神和即时反应 |
| 特写 | 放大手、道具、泪光等有剧情功能的细节 |

| 光型 | 叙事功能 | 有源转译 |
|---|---|---|
| 冷色顶光 | 紧张、压迫、审讯、危险 | 冷月光、高窗冷光、阴冷廊光、偏冷天光 |
| 逆光 | 浪漫、轮廓、发丝光等候选功能 | 真实后/侧后光源；室外无需雾，室内绑定已开启具体开口或已有场内灯火；闭窗纸默认漫射 |
| 底光 | 恐怖、诡异、反常、不安 | 火光、药炉光、烛火下照、火场反光 |
| 丁达尔光 | 仪式感与空间层次的条件候选 | 必须有定向光及已建立的真实散射介质；普通清洁室内禁用，不能凭词库添加香炉、烟雾或开窗 |

## 台词发声

完整公式：情绪语气=声音强弱+语速节奏+呼吸状态+停顿位置+重音位置+尾音变化。

### 标点作用

| 标点 | 作用 | 适用 |
|---|---|---|
| ， 逗号 | 真实短停顿与语义分层 | 思考、犹豫、试探、撒娇、安慰 |
| 。 句号 | 尾音收住、情绪落地 | 平静、冷淡、克制、陈述 |
| ！ 感叹号 | 加强情绪和重音 | 警告、愤怒、兴奋、震惊 |
| ？ 问号 | 疑问、试探或尾音变化 | 疑问、怀疑、不确定、撒娇式询问 |
| ？！ 问号加感叹号 | 质问与爆发叠加 | 愤怒、震惊、强质问 |
| …… 省略号 | 情绪卡住并产生明显停顿 | 难过、委屈、害怕、紧张、舍不得 |
| ～ 波浪号 | 尾音轻快、柔软或拉长 | 开心、撒娇、亲近、温柔 |
| —— 破折号 | 转折、打断、强调或情绪断裂 | 震惊、迟疑、突然意识到、强调 |

### 12类发声模板

节奏参数只引用timing_policy匹配配置。以下按表达提供候选，低沉、温柔、愤怒或掌控感不自动意味着慢；仅有剧情依据的具体位置设计迟疑和停顿。每个重音词必须属于对应人物本次实际发言。

| 情绪 | 六维发声设计 |
|---|---|
| 开心/兴奋 | 声音变亮；句内利落连贯并按配置规划，不吞字；气息轻快；必要语义处分层；实际好消息词加重；尾音自然上扬 |
| 难过/委屈 | 声音放轻；连贯说清，仅有依据的哽咽位置断续；气息按句意调整；真正受伤词前可短停；实际词轻重变化；尾音发虚 |
| 愤怒/质问 | 声音压低或短促爆发；反问连贯，重音前后局部快慢；呼吸受控；必要爆发前短停；实际质问词加重；尾音下压 |
| 警告/压迫感 | 声音低而稳定；句子紧凑，关键位置可短停；呼吸受控；停顿绑定实际事件；实际警告词加重；尾音下压不收软 |
| 紧张/害怕 | 声音放轻；句意连贯，受具体刺激时才断续；呼吸变浅但不固定另占时间；具体危险点可卡住；实际危险词加重；尾音发虚 |
| 怀疑/试探 | 声音略压低；问句自然推进，疑点处局部调整；呼吸克制；观察与对白可并行；实际疑点词加重；尾音克制上抬 |
| 安慰/温柔坚定 | 前半句放轻后半句稳定；自然连贯不拖长；呼吸与发言共享时段；必要处分层；实际承诺词加重；尾音柔和落稳 |
| 思考/犹豫 | 音量偏轻；已知部分连贯，未决词处有依据地犹豫；自然呼吸；只标具体停顿；实际问题词突出；尾音短收或暂悬 |
| 舍不得/挽留 | 声音很轻；挽留句连贯，舍不得的具体词局部迟疑；气息按刺激变化；必要位置短停；实际挽留词克制加重；尾音发虚 |
| 反派/掌控感 | 声音低而稳定；控制感来自稳定节奏和关键词，不逐字拖慢；自然呼吸；有因果依据时短停；实际控制性词加重；尾音下压 |
| 撒娇/亲近 | 声音放软；自然连贯的亲近节奏，不整句拖长；气息轻；必要语义处短停；实际亲近词轻点；尾音柔和短收 |
| 惊讶/不敢相信 | 声音受刺激后抬高；按认知变化局部先顿再接话，不固定起手等待；短促吸气与反应共用时间；意外信息处可停；实际关键词加重；尾音上扬 |

## 不可被美学覆盖的约束

可见性、源文证据、台词容量、光源连续性、正式母版单镜执行完整性和心理音轨口型安全均高于美学增强。
